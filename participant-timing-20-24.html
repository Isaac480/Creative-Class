Was any of that idle time?

jsPsych's fullscreen plugin already logs browser_events — blur/focus pairs that fire when the participant tabs away and back. Summing those gaps is the most direct "were they actually gone" signal in the data, and for all 5 participants it's negligible (0–2.7 seconds total) — nobody left the tab for any real stretch of time.

The big gaps are somewhere else: inside the survey block, and they're legitimate. Looking at per-trial rt, the slowest trials for every participant are open-ended survey forms — not idle time on a captcha or a slider. For participant 23 (the slowest overall):

How to calculate this for future participants

Reusable version of the same parsing approach as last time, extended to also report idle (tab-away) time and a phase breakdown. Drop this into a script and point it at any exported data.csv:

import ast
import csv
import sys

csv.field_size_limit(sys.maxsize)  # json_data cells are large

def analyze_participant(row):
    trials = ast.literal_eval(row["json_data"])

    total_ms = trials[-1]["time_elapsed"]

    # idle time = sum of blur->focus gaps from the fullscreen plugin's browser_events
    events = sorted(
        (be for t in trials for be in (t.get("browser_events") or [])),
        key=lambda e: e["time"],
    )
    idle_ms, blur_start = 0, None
    for e in events:
        if e["event"] == "blur":
            blur_start = e["time"]
        elif e["event"] == "focus" and blur_start is not None:
            idle_ms += e["time"] - blur_start
            blur_start = None

    # time per experiment phase (forward-fill phase across trials that don't set one)
    phase_ms, last_phase, prev_t = {}, None, 0
    for t in trials:
        phase = t.get("experiment_phase") or last_phase
        t_elapsed = t.get("time_elapsed", prev_t)
        if phase:
            phase_ms[phase] = phase_ms.get(phase, 0) + (t_elapsed - prev_t)
        prev_t, last_phase = t_elapsed, phase

    return {
        "id": row["id"],
        "total_min": round(total_ms / 60000, 2),
        "idle_sec": round(idle_ms / 1000, 1),
        "phase_breakdown_sec": {k: round(v / 1000, 1) for k, v in phase_ms.items()},
    }

with open("data/temp/data.csv") as f:
    for row in csv.DictReader(f):
        print(analyze_participant(row))

Two things to know before reusing it:

  • json_data is a Python-repr string (single quotes, True/None), not strict JSON — ast.literal_eval, not json.loads.
  • Idle detection is only as good as browser_events — it currently catches tab switches (blur/focus) and fullscreen exits, which is what caught participant 9's 13-minute gap in the last batch. It won't catch someone who stays on the tab but walks away without switching windows; if that turns out to matter, the fix is adding a visibility-based heartbeat ping on the frontend, not a change to this analysis.
