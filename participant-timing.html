Does rt tell you how long the experiment took?

data/temp/data.csv · participants 7–10

Short answer: not directly, but you can get duration from the same rows. Each participant's json_data column is a JSON array of jsPsych trial records. Every trial has two relevant fields:

  • rt — time spent on that single trial (reaction time)
  • time_elapsed — running total of milliseconds since the experiment started, as of the end of that trial

So the time_elapsed value on the last trial is the total experiment duration — that's the number to use, not any single rt. (Summing all the rts gives nearly the same number, since time_elapsed is essentially a running sum of the rts plus small render/loading gaps — see table below.)

Participant 9 is an outlier. One trial (the second-to-last survey page) has rt = 781,307 ms ≈ 13.0 minutes, far above every other trial for any of the four participants (next-largest is ~3.5 min). That's almost certainly the participant leaving the tab open/idle rather than actually reading that page for 13 minutes. If you drop that one gap, participant 9's real engaged time is ≈ 14.1 min — in line with the others.

Average excluding that outlier gap: 17.0 minutes.

How to pull this yourself

The json_data cell is a Python-repr-style string (single-quoted), not strict JSON — use ast.literal_eval() rather than json.loads() to parse it. Then:

import ast
trials = ast.literal_eval(row['json_data'])
duration_ms = trials[-1]['time_elapsed']   # total time for that participant
